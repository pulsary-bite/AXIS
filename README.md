# AXIS Trading Lab

Public research code for a paper-only market simulator. No live orders, credentials, personal data or account access. Start balance: virtual 50 USDT. Profit is not guaranteed.

Python 3 standard library. Run tests: `python -m unittest -v`. Run one market cycle: `python worker.py --once`.

Cloud scheduling remains disabled until durable private state storage is configured. Do not commit databases, logs, credentials or account information.
